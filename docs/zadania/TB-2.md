
# TB-2 – Baza danych

## Część 1

### Cel zadania

Dodanie tabeli tasks do bazy danych TaskBoard
oraz wykonanie zapytań SQL.

### Do wykonania

1. Utworzyć branch feature/tb-2-baza.
2. Dodać tabelę tasks do bazy danych.
3. Dodać 10 zadań testowych.
4. Napisać 10 zapytań SQL w queries.sql.
5. Zrobić kopię zapasową bazy danych.
6. Odtworzyć kopię w bazie taskboard_test.
7. Sprawdzić liczbę rekordów w obu bazach.
8. Poprawić 5 błędów w bugs.js.
9. Utworzyć plik TB-2.md.
10. Zrobić Pull Request i scalić zmiany.
